# From Script to Visual – Method

## 1. Parse
- Identify **promise/question** of the video, **time span**, **places**, **people/creatures**, **numbers/dates**, **claims to verify**.
- Tag each sentence with: *era · place · characters · action · emotion · key fact/number · symbol*.

## 2. Beat-split
Split at: change of era/place/speaker, new idea, number/date, list item, myth↔fact switch, quote.
Target 3–8 s per beat (≈ 8–20 Hindi words). Long sentences → 2 beats (e.g., wide then push-in on detail).
Mark **hero beats** (strongest facts/emotions).

## 3. Map to visuals
| Script cue | Possible visual (choose per context, don't always use the first) |
|---|---|
| A date/era shift | era stamp + palette change + camera tilt/scrub |
| A number | counter, tally, bar, icon crowd |
| "Imagine…" | thought-bubble style soft-edged scene labelled imagined |
| Cause→effect | domino arrows / before-after split |
| Invention | object build-up with sparkles, hands showing use, ripple of change |
| Conflict | opposing colour sides, flags, silhouettes, restrained (no gore) |
| Daily life | multi-vignette cutaway |
| Mystery / unknown | silhouette, fog, "?" pop |
| Migration/trade | map route draws itself, tiny caravans/ships |
| Scale | zoom-out, comparison silhouette |
| Today link | match-cut from ancient object to modern equivalent |

## 4. Design each beat
Use `templates/shot_list_template.md`. Always state: era+year, place, time of day, characters (via cast system), props, palette (3–4 colours + accent), shot size & camera move, motion, device, on-screen text (script language), transition, SFX, image prompt, optional video prompt.

## 5. Assets list
Extract unique backgrounds, characters (with variants), creatures, props, effects, text cards → generate once, reuse consistently.

## 6. Timing
With audio: align to word timestamps/SRT. Without audio: ≈ 2.4–3.0 Hindi words/sec for explainer pacing.

## 7. QA checklist
- [ ] Every visual justified by a script line
- [ ] Facts/dates match script or flagged `[verify]`
- [ ] No anachronisms (e.g., no stirrups in Rome, no horned Viking helmets, no humans with non-avian dinosaurs)
- [ ] Cultures depicted respectfully and with variety
- [ ] Device variety rules from `interest-engine.md` pass
- [ ] Text spelling (Devanagari conjuncts), safe margins
- [ ] Characters follow the cast construction; creatures follow the creature kit
- [ ] No gore; sensitive events handled with restraint
