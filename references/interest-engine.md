# Interest Engine – keep viewers watching (without a fixed plan)

Goal: every few seconds give the eye something new and the mind a reason to stay. **Choose devices per beat from the script; never run a fixed sequence.**

## 1. Hook (0–5 s)
Pick ONE based on the script's strongest idea:
- **Impossible fact** ("T. rex lived closer in time to us than to Stegosaurus") → split-screen timeline stretch.
- **Question on screen** with a dramatic visual (huge "?" pop, silhouette).
- **Scale shock** → start tiny, zoom out to reveal giant (or vice-versa).
- **Mystery object** (a bone, a tablet, a coin) → "what is this?"
- **Before/After or Then/Now** freeze-frame.
- **Countdown / big number** ("66,000,000").
Hook must be visual first, text second. Never start with a title card unless the script is title-first.

## 2. Device menu (use any, mix freely)
| Device | Use when the script… |
|---|---|
| **Zoom-out reveal** | reveals scale (planet, empire, timeline) |
| **Timeline scrub** (camera races along a time-bar, objects morph by era) | covers long spans |
| **VS split-screen** | compares two things/cultures/ideas |
| **Myth vs Fact** (stamp, tick/cross) | corrects a misconception |
| **Counter/dial** | has numbers, populations, years |
| **Map journey** (route draws itself, cut-out icons travel) | migration, trade, conquest |
| **Cutaway / cross-section** (peel a wall, see inside) | explains how something works/was built |
| **Day-in-the-life vignette** (3 tiny scenes in a row) | shows culture/daily life |
| **Object through time** (same bowl/lamp/wheel across eras) | follows a theme |
| **Silhouette reveal** (black shape → colour pop) | introduces a person/creature |
| **Chapter card** | marks a big shift (use sparingly) |
| **Ripple / shock-ring** | a sudden event (impact, invention, discovery) |
| **Stacked list build** (items drop in) | enumerations |
| **Macro → micro** (cell → hand → tool) | evolution, craft |
| **Parallel worlds** (two scenes simultaneous in different places) | "meanwhile in…" |
| **Speech bubble / thought bubble** | quotes, imagined thoughts (label as imagined) |
| **Cause→Effect chain** (domino arrows) | explains consequences |
| **Quiz pause** ("guess before I tell you") | mid-video engagement |
| **Sound-led beat** (visual silence + a sound) | emotional or dramatic moments |

## 3. Anti-repetition rules
- Never use the same device in two consecutive beats.
- Never use the same background + same shot size in two consecutive beats.
- At least one **pattern interrupt** (device change, palette flip, scale change, motion style change) every 5–8 s.
- Do not use a chapter card more than once per ~60 s of video.
- Don't open or close two different videos with the same composition.
- Over any 30 s window: ≥ 3 different shot sizes, ≥ 2 different palettes/sky states, ≥ 2 different motion types.

## 4. Open loops & payoffs
- Plant a question early ("what happened next?"), pay it off later; show a partial image (silhouette, fog, shadow) and reveal 10–20 s later.
- Use **"wait, there's more"** micro-reveals: object → hidden detail → bigger meaning.
- End with a **bookend** (return to opening image changed by what we learned) or a **forward-flash** to today.

## 5. Emotional range
Wonder · humour (gentle) · tension · awe · empathy · pride. Alternate tension and release; give big beats room (slower push-in, music dip).

## 6. Rhythm tools
- Hero beats: mark 3–5 per minute-ish; give them close-up/special effect + SFX swell.
- Quick-cut montage of 3–4 icons for lists (≤ 1 s each).
- Hold a calm wide shot after intense beats.
- Match visual cut to word emphasis in the narration.

## 7. Sound ideas (era-flavoured)
Rumble & roars (muffled, friendly), wind, fire crackle, drums, flute, bells, market murmur, printing clack, steam hiss, typewriter, radio static, rocket countdown, notification ping. Keep music instrumental, curious tone; avoid heavy epic bombast unless script is dramatic.

## 8. Variety self-test (run before delivering)
List the device used per beat in order. If any two neighbours match, or the list reads like a template, redesign.
