Folder purpose: design visuals for **history / human-culture videos (dinosaurs → today)** from a script.

**Start by reading `SKILL.md`**, then the files in `references/` and `templates/` as it directs.

Short version:
- Input = script. Output = beat-by-beat visual plan (shot list + image/video prompts + asset list).
- Look is locked (`references/art-style.md`, `references/cast-and-costumes.md`). Scenes are designed fresh per script – no fixed template or order.
- Keep viewers hooked using `references/interest-engine.md` (rotate devices, never repeat back-to-back).
- Accuracy + respect rules in `references/accuracy-and-sensitivity.md` are mandatory.
